# Knowledge Summaries

This directory contains **pre-compressed summaries** of knowledge sources.

## Purpose

Instead of loading entire source files (~10-100KB each), the guardian loads these summaries (~1KB each) to understand content without consuming excessive context.

## Summary Format

Each summary follows this structure:

```markdown
# [Source File Name]
**Last Updated**: ISO timestamp
**Checksum**: First 16 chars of SHA-256
**Lines**: start-end

## Key Points
- Bullet points of main concepts
- Maximum 10 bullets
- Each bullet ≤100 chars

## Definitions
- term: definition (if this section defines terms)

## Dependencies
- References: [files this references]
- Referenced by: [files that reference this]

## Verification Required
- [ ] Critical claims that need source verification
```

## Generation

Summaries are generated by the `swarm-knowledge-guardian` agent:
1. When a source file's checksum changes
2. During full knowledge audits
3. When explicitly requested
