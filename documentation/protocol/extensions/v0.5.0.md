## What Each Extension Adds

### SW4-001: Failure Semantics

Defines normative failure handling for the Negotiation Room pattern (Core §17.5):
quorum calculation rules, partition detection and recovery, and timeout behavior
when participants fail to respond within bounded windows.

### SW4-002: Timeout Profiles

Replaces the universal 30-second timeout default with per-service configurable
timeout profiles. Allows deployments to tune timeouts independently for
registry, router, scheduler, and extended services based on operational
characteristics.

### SW4-003: Observability

Adds normative observability requirements: OpenTelemetry-compliant distributed
tracing, Prometheus metric endpoints, and health check endpoint conventions.
Extends Core §4 observability framework with concrete implementation guidance.

### SW4-004: Inter-Swarm Composition

Defines how one SW4RM swarm composes with another via a Gateway Agent contract
(`SWARM_GATEWAY` registration type). Adds cross-swarm budgeting
(`BudgetEnvelope`), parent-child trace linkage (`parent_correlation_id`),
cascading cancellation (`CancelDelegation`), and first-class overload signaling
(`OVERLOADED` error code). Preserves substitutability: parent orchestration
treats swarms and agents uniformly.

### SW4-005: Spillover Routing

Defines normative spillover routing for cross-swarm delegation under overload.
Standardizes peer discovery from the registry, redirect signaling
(`REDIRECT` error code, `redirect_to_agent_id`), redirect-chain limits
(`max_redirects`), health-aware target selection, and budget accounting across
redirect hops. Opt-in via `allow_spillover_routing`.
