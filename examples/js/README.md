# SW4RM JS SDK Examples

These examples mirror the Python examples to demonstrate common flows. Replace host addresses, IDs, and payloads as needed.

Run tips:
- These are TypeScript-flavored snippets; adapt to your build as needed.
- You’ll need running SW4RM services (registry/router/scheduler/etc.).
- For package imports, use `@sw4rm/js-sdk` in external projects.
